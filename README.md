# ApBarcelona

Plataforma de apartamentos turísticos en Barcelona. Los usuarios pueden buscar, reservar y publicar apartamentos. Construido con PHP, MySQL, CSS y JavaScript.

## Requisitos

- PHP 7.4+
- MySQL 5.7+
- Servidor web (Apache, Nginx)

## Instalación

1. Ejecuta `database.sql` en phpMyAdmin o MySQL
2. Configura `conexion.php` con los datos de tu base de datos
3. Opcional: configura `email_config.php` con credenciales SMTP
4. Despliega los archivos en tu servidor web
